# Frailty Risk Screening: Study Instrument

Deployment branch for a research study application used in a Master's thesis at
TU Berlin. It contains only the runtime code required to serve the participant
instrument.

The application is live at https://frailtyclassifier.streamlit.app

Study data, the dataset, project documentation and analysis code are not part of
this branch.
